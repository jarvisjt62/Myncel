# 🎬 Recording Cheat Sheet (open this on your phone while recording)

## Before you hit record
- [ ] Loom or Game Bar (NOT the old recorder with watermark)
- [ ] Chrome window — maximized but NOT F11 (URL bar must show)
- [ ] One Gmail account signed in (the test user)
- [ ] Google Sheets currently **disconnected** in Myncel
- [ ] 2-3 work orders exist for the export demo

## After recording
