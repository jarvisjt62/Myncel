## Video 1: OAuth Consent Screen Workflow

### What to Record (2-3 minutes)

**Step 1: Start Fresh**
1. Open browser in **incognito/private mode**
2. Navigate to your Myncel app URL
3. Make sure you're logged out of Google

**Step 2: Show Login Screen**
1. Show the login page with "Sign in with Google" button
2. Hover over the button to highlight it
3. Click "Sign in with Google"

**Step 3: Show Google OAuth Screen**
1. **CRITICAL:** Show the Google consent screen clearly
2. Show the app name "Myncel" on the consent screen
3. Show the permissions being requested
4. Point to each permission with your mouse cursor
5. Say: "This shows the OAuth consent screen with the permissions Myncel is requesting"

**Step 4: Grant Permissions**
1. Click "Allow" on the consent screen
2. Show the redirect back to your app
3. Show successful login
4. Show user is now authenticated

**Step 5: Show User Profile**
1. Show the user's Google profile/email displayed
2. Show any user-specific data
3. Say: "The user is now logged in via Google OAuth"

### Script for Video 1:
```
"Hi, I'm demonstrating the OAuth consent screen workflow for Myncel.
First, I'll navigate to the Myncel application.
Here's the login screen with the 'Sign in with Google' button.
When I click this, it redirects to Google's OAuth consent screen.
You can see the app name 'Myncel' and the permissions being requested.
I'll click 'Allow' to grant these permissions.
Now I'm redirected back to Myncel, and I'm successfully logged in.
The OAuth flow is complete."
```

## Recording Instructions

### Recommended Tools

**Option 1: Loom (Easiest)**
1. Go to https://www.loom.com
2. Sign up for free account
3. Download Loom desktop app
4. Click record → Select screen → Start recording
5. Follow the scripts above
6. Stop recording → Get shareable link

**Option 2: OBS Studio (Free, More Control)**
1. Download from https://obsproject.com
2. Install and open
3. Add "Screen Capture" source
4. Set recording quality to 1080p
5. Click "Start Recording"
6. Follow scripts
7. Click "Stop Recording"
8. File is saved to your computer

**Option 3: Windows Game Bar (Built-in)**
1. Press `Win + G` to open
2. Click "Start Recording"
3. Follow scripts
4. Press `Win + Alt + R` to stop
5. Video saved in Videos/Captures folder

**Option 4: Mac QuickTime (Built-in)**
1. Open QuickTime Player
2. File → New Screen Recording
3. Click record
4. Follow scripts
5. Stop recording
6. Save file

## Recording Tips

### Before Recording
- [ ] Test your app - make sure everything works
- [ ] Clear browser cache/cookies
- [ ] Use incognito mode for clean demo
- [ ] Have sample data ready (equipment, work orders)
- [ ] Test Google OAuth flow first

### During Recording
- [ ] Speak clearly and slowly
- [ ] Use mouse cursor to highlight important elements
- [ ] Pause briefly between actions
- [ ] Keep videos under 5 minutes each
- [ ] Record in 1080p or higher resolution
- [ ] Use good lighting if showing face (optional)

### After Recording
- [ ] Watch the video to check quality
- [ ] Make sure OAuth consent screen is clearly visible
- [ ] Ensure audio is clear
- [ ] Upload to YouTube as "Unlisted"
- [ ] Get the shareable URL
